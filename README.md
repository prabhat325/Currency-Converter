# 💱 Currency Converter

A simple and responsive **Currency Converter Web App** built using **HTML, CSS, and JavaScript**.  
It allows users to convert currencies in real time using live exchange rates. 🌍💸

---

## 🚀 Features

- 🌎 Convert between multiple international currencies
- 🔄 Real-time exchange rates
- 🇺🇸 Country flags for currencies
- 📱 Responsive design for mobile & desktop
- ⚡ Fast and lightweight interface
- ❌ Input validation for invalid amounts

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Currency Exchange API

---

## 📂 Project Structure

```bash
Currency-Converter/

```

## 🎯 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/currency-converter.git
```

2. Open the project folder

3. Run `index.html` in your browser
